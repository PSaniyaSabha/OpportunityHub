# OpportunityHub

Create OpportunityHub, a modern, minimal, premium, and fully responsive web application for students to discover Internships, Full-time Jobs, Freelance Opportunities, and Hackathons.

Set up the database schema and backend integration with Supabase / PostgreSQL including:
- Tables: profiles, opportunities, saved_opportunities, applications with proper foreign keys, indexes, and RLS policies
- Supabase Auth (student signup/login, profiles)
- Opportunities browsing with category filters (Internships, Full-time Jobs, Freelance, Hackathons), search, tags, location, deadline tracking, and status
- Detailed opportunity view, bookmarking / saved opportunities, and student application flow
- Storage configuration for student resumes/avatars
